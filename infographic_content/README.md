# Infographic content

This folder contains Markdown source files derived from the site's HTML pages. Each Markdown file is intended to be fed to a notebook / LLM pipeline (e.g., NotebookLM) to generate an infographic per page.

Structure:
- `*.md` — Markdown extraction for top-level pages (title, description and main content)
- `protocols/*.md` — Markdown files for protocol pages
- `context/original_html/` — Copies of the original HTML files used as reference (images and diagrams referenced in these HTML files are relative paths)

Usage tips:
- Review the images/diagrams referenced in the original HTML files (in `context/original_html/...`) and include them when requesting infographic generation.
- If you prefer per-protocol subfolders with richest context (images, example data), copy specific files from `context/original_html/` into a per-protocol folder.

Infographic implementation notes:
- Use the `.infographic` container with modifier classes `.infographic--landscape` or `.infographic--portrait` to control aspect ratio and responsive behavior.
- Place SVG diagrams under `docs/assets/images/diagrams/` and reference them from `docs` pages as `assets/images/diagrams/<name>.svg`.
- For large raster images, add `loading="lazy"` and `decoding="async"` attributes to improve load performance.

Generated by `scripts/extract_infographic_content.py` — run this script again to refresh the Markdown if the site HTML changes.
