INFOGRAPHICS — CRAVING, ATTENTION, & RECOVERY SYSTEM
Purpose: Visual Models & Protocols
Last updated: 2025-12-15
================================================================================

This directory contains all primary and reference infographics used across the
site. These visuals support the core narrative: how craving forms, how attention
is hijacked, and how autonomy can be reclaimed through evidence-based practices.

Infographics are classified as:
- CORE (designed for direct site integration)
- SUPPORTING (used inline or as expandable sections)
- REFERENCE (library or downloadable material)

--------------------------------------------------------------------------------
COLOR SYSTEM (CORE INFOGRAPHICS)
--------------------------------------------------------------------------------
All CORE infographics are designed to align with the site palette:

Canvas        #0f172a   Deepest background
Surface       #1e293b   Primary container background
Elevation     #334155   Cards and raised UI
Accent        #c9a961   Gold highlight, borders, focus cues
Primary Text  #f8fafc   Headings
Secondary     #cbd5e1   Body text

Only CORE graphics should visually match this system.

DESIGN RULES
--------------------------------------------------------------------------------

- REFERENCE graphics should never be used as hero visuals

- Supporting graphics should reinforce, not repeat, concepts
